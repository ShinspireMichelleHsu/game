# 高難度測試挑戰：電商流程自動化
目標網站：https://www.saucedemo.com/

測試步驟：
1. 前往網站首頁。
2. 在 Username 輸入框填入 "standard_user"。
3. 在 Password 輸入框填入 "secret_sauce"。
4. 點擊 "Login" 按鈕進入產品頁。
5. 點擊右上方的排序下拉選單 (Product Sort Container)，選擇 "Price (high to low)"。
6. 驗證頁面上第一個產品的價格是否顯示為 "$49.99"。
7. 執行螢幕截圖，命名為 "sauce_test_result.png"。
